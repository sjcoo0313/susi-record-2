# 🎓 고3 수시 6장 대학 지원 관리기 (UniCard Tracker)

고3 담임선생님과 학생들이 수시 6장 지원 내역을 편리하게 입력하고, 실시간으로 통계를 확인하며, 서식이 적용된 엑셀(Excel) 파일로 다운로드할 수 있는 웹 애플리케이션입니다.

---

## 📌 주요 기능

### 1. 📱 학생용 지원서 입력 (모바일 / PC 겸용)
- **간편 본인확인**: 학번(4자리 예: 3201) + 성명 + 비밀번호(4자리 예: 생년월일)로 본인 확인 및 언제든 재접속 수정 가능.
- **수시 6장 카드 입력 (1~6순위)**:
  - 대학명 (주요 대학 빠른 선택 칩 제공)
  - 학과(학부/전공)명
  - 전형 유형 (학생부교과 / 학생부종합 / 논술 / 실기 / 수능위주 / 기타) + 세부 전형명
  - 대학 산출 내신등급 (소수점 둘째자리)
  - **지원 성향**: 🔴 **상향** (내신보다 1등급 이상 도전) / 🟡 **소신** (적정 등급컷 50~70%) / 🟢 **안정** (등급컷 50% 이내)
  - **등록/합격 상태**: 접수완료, 1차합격, 최종합격, 불합격, 예비번호, 🎓 최종등록
  - 비고 / 메모 (수능 최저기준, 면접일 등)
- **실시간 작성 완료도 표시**: 1~6순위 진행 상황 게이지 및 저장 알림.

### 2. 💻 선생님 관리자 대시보드
- **마스터 비밀번호 로그인** (기본 비밀번호: `1234`)
- **교실 칠판/스크린용 QR 코드**: 상단 `접속 QR코드` 버튼을 누르면 교실 TV/빔프로젝터에 띄울 수 있는 대형 QR코드와 접속 주소가 표시됩니다.
- **실시간 종합 통계**:
  - 총 제출 학생 수 및 총 지원 건수
  - 상향 / 소신 / 안정 지원 비율 프로그레스 바
  - 인기 지원 대학 TOP 10 순위 칩
  - 최종 등록 및 최종 합격 학생 수
- **다차원 검색 및 다중 필터**:
  - 학번/이름 검색
  - 대학별 필터 (클릭 시 해당 대학 지원자만 즉시 확인)
  - 전형유형별, 지원성향별, 합격/등록상태별 필터
- **학생별 6장 상세 확인 및 직접 수정**: 학생의 6개 카드 수정 및 비밀번호 분실 시 4자리 재설정 기능.
- **📥 서식 적용 2개 시트 엑셀(Excel) 다운로드**:
  - **시트 1 [학생별 종합 현황]**: 학생 1명당 1행으로 1~6순위 가로 정렬 (인쇄 및 보고서용)
  - **시트 2 [지원건별 상세 분석]**: 학생수 × 6행 세로 정렬 (피벗 테이블 및 통계 분석용)
  - 상향(빨강), 소신(노랑), 안정(초록), 등록(보라) 자동 컬러 서식 적용

## 🚀 실행 방법

### 방법 1: 윈도우에서 더블클릭 실행 (가장 간단한 방법)
1. 폴더 안의 **`start.bat`** 파일을 더블 클릭합니다.
2. 자동으로 브라우저(`http://localhost:3000`)가 실행되며 바로 사용하실 수 있습니다!

### 방법 2: 명령줄(터미널)에서 실행
```bash
# 1. 의존성 설치
npm install
cd client && npm install && npm run build && cd ..

# 2. 서버 실행
npm start
```

## 📱 교실에서 학생들에게 공유하는 법
1. 선생님 컴퓨터와 학생 스마트폰이 **같은 학교/교실 Wi-Fi**에 연결되어 있는지 확인합니다.
2. 화면 상단의 **[접속 QR코드]** 버튼을 눌러 교실 전자칠판이나 빔프로젝터에 띄웁니다.
3. 학생들은 스마트폰 기본 카메라 앱으로 QR 코드를 비추면 즉시 접속하여 본인 학번으로 입력을 시작할 수 있습니다.
